# Game data dump: Valheim 1.0.20

Written by `co_dump` on 2026-10-26 (vanilla plus Jötunn, English). Reference data for designing and checking mod features, e.g. the corruption mod's trophy, creature and material tables.

- `biome_sources.csv` (4 MB, every raw biome source) is left out; re-run `co_dump` for it.
- The biome columns come from the resolver as it was **before** the 2026-10-26 fixes. Several Deep North items are wrongly in Meadows, and Bloodgold is unplaced. Re-dump after re-testing for corrected biomes.
- This is Iron Gate's game data: fine in this private repository for development, but never ship it with a mod.
